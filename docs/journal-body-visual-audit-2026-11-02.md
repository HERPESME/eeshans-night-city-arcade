## Figure contract

Figures use semantic HTML, actual headings, labelled ordered lists and captions. Text is readable in server-rendered HTML and assistive technology, rather than embedded in an image. Comparison, flow, sequence, record-model, state and measurement layouts share the journal palette while using different information structures. At narrow widths columns stack without shrinking the text. Existing raster imagery remains WebP; GIFs are untouched. Reading-time and structured-data word counts include the added explanations.

Public diagrams are teaching models. They do not claim to reproduce the production schema, an actual trace, measured traffic or an unshipped design as deployed behaviour. A future screenshot must demonstrate the discussed UI state and retain clear provenance. No minimum picture count is an editorial requirement.
